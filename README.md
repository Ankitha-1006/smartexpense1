# 💰 Smart Expense Tracker

A modern and responsive web application to track daily expenses, visualize spending patterns, and generate smart financial insights.

---

## 🚀 Features

### 📊 Dashboard

* View total expenses for the month
* Check remaining balance based on income
* Track total number of transactions
* Visualize spending using:

  * Pie chart (category-wise)
  * Bar chart (weekly trends)

---

### ➕ Add Expense

* Add new expenses with:

  * Amount
  * Category (Food, Travel, Bills, Shopping, Others)
  * Date
  * Notes

---

### 📋 Transactions

* View all recent expenses
* Sorted by latest date
* Option to delete transactions

---

### 💡 Smart Insights

* Automatically generated insights such as:

  * High spending category alerts
  * Weekly spending comparisons
  * Budget warnings

---

### 📄 Reports

* Generate and download monthly expense report as PDF
* Includes:

  * Summary
  * Category breakdown
  * Recent transactions

---

### ⚙️ Settings

* Set or update monthly income
* Toggle between Light and Dark mode 🌙

---

## 🎨 UI Highlights

* Clean and modern fintech-style design
* Fully responsive (mobile + desktop)
* Smooth animations and transitions
* Sidebar navigation layout

---

## 🛠️ Tech Stack

* *Frontend:* HTML, CSS (Tailwind CSS), JavaScript
* *Charts:* Chart.js
* *Icons:* Lucide Icons
* *PDF Generation:* html2pdf.js
* *Data Handling:* Local data (via SDK)
